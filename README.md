# Descript

## Tunic Translation Assistant

Descript lets you collect all the phrases and sentences you find in game and sort and filter them by runes and any
current working translations, making translation a much easier process than by using pen and paper. 

To use, add a sentence using the Add Sentence button at the top of the screen.
This will pull up a dialog, where you can input the sentence and any relevant context, for easier filtering later.
When inputting a sentence you have four modes, which you can switch between using keyboard shortcuts:

* None
  * The default. For inputting raw english text

* Rune
  * Shortcut: Control/Command + R
  * Input runes from your list that have a translation. 
  * You can use the up and down arrow keys to select a translation if multiple runes have the same translation.
  * If the current search is not empty, pressing backspace will work on the search text, otherwise it will delete runes in the current sentence input entry

* Word
  * Shortcut: Control/Command + Shift + R
  * Same as above, but searches words instead of runes

* Shape
  * Shortcut: Control/Command + S
  * Once the left screen shows the rune you desire, press enter to insert it.
  * Backspace works as normal here
  * Input Runes by their component lines, using the keys below:
    * W - Upper Top-Left
    * R - Upper Top-Right
    * S - Upper Bottom-Left
    * F - Upper Bottom-Right
    * E/D - Upper Vertical Bar
    * U - Lower Top-Left
    * O - Lower Top-Right
    * J - Lower Bottom-Left
    * L - Lower Bottom-Right
    * I/K - Lower Vertical Bar
    * A - Left Vertical Bar
    * M - Lower Dot

All modes allow you to use punctation and spaces, and move the cursor using the left and right arrow keys.

Once you have one or more sentences, you can click on any rune in a sentence to guess their meaning, and assign a confidence level to that translation guess.
Once all runes in a word have a high confidence level translation assigned, you can guess the translation for that particular sequence of runes.
You can always click on words to change or remove their translation. 

To remove a translation, simply set it to nothing, and any instances of that word in the sentence
view will be replaced by the individual runes, which you can again edit by clicking on them.

You can also always edit individual runes in the left pane.

Translations will auto apply to ever sentence, making it easy to filter sentences for words with the least amount of unknowns.
When searching sentences you can also use the input modes and shortcuts listed above, and you can right-click on runes, words, or sentences for more filtering options
